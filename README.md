# 🔍 示例结构说明

每个平台下的子目录就是一个 **真实任务示例**，包含：

- `input.xxx`  
- `output.xxx`  
- `readme.md`（用途说明 + 使用说明）  
- （可选）`flow.json` / 脚本文件

# 🤝 Contributing

欢迎提交任何平台的 **真实可运行示例**：

- GPT / Qwen / Llama 示例  
- ComfyUI flow  
- Dify flow  
- Coze bot flow  
- NanoBanana 示例  
- LangChain pipeline  
- 工具脚本示例  

**规则：**

1. 顶层按平台分类（gpt / nano-banana / comfyui…）  
2. 每个示例为独立文件夹  
3. 必须包含 input / output / readme.md  
4. 文件名使用小写 + 中横线  
5. 大文件放 assets 或外链
