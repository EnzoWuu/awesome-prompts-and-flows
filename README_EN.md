# Awesome Prompts and Flows 🌟  
[中文版](README.md)

A cross-platform collection of **real, practical AI examples**, covering:

**LLM · NanoBanana · ComfyUI · Dify · Coze · LibLib**

Each example includes:

- `input.xxx` (example input)  
- `output.xxx` (actual model output)  
- `prompt.txt` or `flow.json` or `code.py` (core logic)  
- `readme.md` (documentation)  

All examples are fully reproducible — no fluff, no boilerplate.

## 🤝 Contributing

You may contribute examples for:

- GPT / Qwen / Llama  
- ComfyUI JSON  
- Dify flows  
- Coze bot flows  
- NanoBanana tasks  

**Contribution Rules:**

1. Organize by platform  
2. Each example must be an independent folder  
3. Must include input / output / readme + prompt/flow/code  
4. Use lowercase + hyphens  
5. Large files should be externally hosted
